# Mind Corkboard

**Pin what stays with you.**

A personal digital corkboard for books, quotes, photos, memories, and everything else worth pinning.

## Stack

- React + Vite + Tailwind CSS
- Framer Motion (drag, pin, hover, expand)
- html-to-image (board export)
- localStorage persistence

## Develop

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start local server
- `npm run build` — production build
- `npm run preview` — preview production build
